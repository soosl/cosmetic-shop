# Главная merimarket — демонстрационная вёрстка

Откройте `index.html` двойным щелчком в браузере. Установка пакетов и сборка не нужны. Страница работает без интернета.

Для передачи заказчику нужны три файла в одной папке: `index.html`, `styles.css`, `script.js`. Готовый архив — `merimarket-preview.zip`.

Вёрстка основана на первом макете Blue & Butter. Есть адаптации для компьютера, планшета и телефона. Вместо изображений — простые цветные заглушки, вместо фирменного логотипа — текстовый кандидат `merimarket`.

Поиск, подборки, информационные разделы и контакты показывают сообщения-заглушки. Добавление в корзину и избранное демонстрирует отклик интерфейса; данные не сохраняются и заказ не оформляется. Товары, бренд FORME и цены условные. Название магазина ещё не утверждено.

Страница использует системные шрифты Arial и Georgia вместо Manrope и Cormorant Garamond из Figma, поэтому не требует загрузки внешних ресурсов.
