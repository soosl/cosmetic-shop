# Три варианта главной

Откройте index.html в этой папке — это страница выбора вариантов.

- v1/index.html — Blue & Butter, merimarket.
- v2/index.html — Olive & Rose, merimarket.
- v3/index.html — Berry & Lime, MERIBREND.

Названия пока не утверждены. Версии содержат демонстрационные данные, простые заглушки изображений и адаптивные стили. На телефоне — нижняя панель и раскрываемый подвал. Поиск, подборки и внутренние разделы не подключены к магазину. Корзина и избранное демонстрируют отклик без сохранения данных.

Обычные HTML/CSS/JS, без установки пакетов, сборки и внешних ресурсов. Каждая версия независима: её index.html, styles.css и script.js лежат рядом. Папку code можно публиковать целиком; при публикации всего репозитория страница выбора доступна по относительному адресу code/, варианты — code/v1/, code/v2/, code/v3/. Пути работают и в подкаталоге GitHub Pages.

Архивы не создаются. V1 при добавлении V2 и V3 не изменялась.

Проверены синтаксис JavaScript, внутренние ссылки, локальные ресурсы и основные цветовые пары. Визуальная проверка адаптивов в браузере пока не выполнена.
